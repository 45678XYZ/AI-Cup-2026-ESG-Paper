# Poster runbook

## Build the A0 poster (LaTeX, the version to submit)

```bash
cd poster
tectonic poster.tex --outdir build --keep-logs
```

The output is `build/poster.pdf`: one A0 portrait page (841 × 1189 mm) with every font embedded. The poster reads `../figures/figure1_hierarchy.pdf` and `../tables/table{2_main,4_contrasts,7_multilingual_mechanism}.tex` directly, so a table regenerated by `analysis/` reaches the poster on the next build.

Check before submitting:

```bash
pdfinfo build/poster.pdf | grep -E "Pages|Page size"   # 1 page, A0
pdffonts build/poster.pdf                              # every row "emb yes"
```

## Paper2Poster pipeline (alternative, not executed)

This machine cannot run it: there is no `OPENAI_API_KEY`, LibreOffice is not installed, and the local-model route needs `vllm` on a CUDA GPU. The command below is the upstream pattern with A0 portrait dimensions.

```bash
git clone https://github.com/Paper2Poster/Paper2Poster.git && cd Paper2Poster
pip install -r requirements.txt          # also needs LibreOffice and Poppler
echo "OPENAI_API_KEY=..." > .env

mkdir -p dataset/ntcir19_validity_layer
cp <paper-repo>/manuscript/build/main.pdf dataset/ntcir19_validity_layer/paper.pdf
cp <paper-repo>/poster/poster.yaml        dataset/ntcir19_validity_layer/poster.yaml

python -m PosterAgent.new_pipeline \
    --poster_path="dataset/ntcir19_validity_layer/paper.pdf" \
    --model_name_t="4o" \
    --model_name_v="4o" \
    --poster_width_inches=33.11 \
    --poster_height_inches=46.81
```

It produces an editable `poster.pptx`, not a PDF. Export it to PDF with embedded fonts, then check every number against the paper, because the text is generated by GPT-4o rather than copied from the paper.
