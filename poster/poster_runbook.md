# Poster runbook

## Build the A0 poster (LaTeX, the version to submit)

```bash
cd poster
tectonic poster.tex --outdir build --keep-logs
```

The output is `build/poster.pdf`: one A0 portrait page (841 × 1189 mm) with every font embedded. The logos come from `assets/`; the NTCIR logo is TikZ, so the build needs no SVG converter. The poster reads `../figures/figure1_hierarchy.pdf` and `../tables/table{2_main,4_contrasts,7_multilingual_mechanism}.tex` directly, so a table regenerated by `analysis/` reaches the poster on the next build.

Check before submitting:

```bash
pdfinfo build/poster.pdf | grep -E "Pages|Page size"   # 1 page, A0
pdffonts build/poster.pdf                              # every row "emb yes"
```
