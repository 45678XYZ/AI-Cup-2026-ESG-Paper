\block{1\,$\cdot$\,Problem: plausible fields, invalid tuple}{
  \begin{itemize}
    \item Four fields describe one ESG claim: promise status (PS), verification
      timeline (VT), evidence status (ES), evidence quality (EQ).
    \item Hard implications: PS\,=\,No forces VT\,=\,ES\,=\,EQ\,=\,N/A, and
      ES\,=\,No forces EQ\,=\,N/A.
    \item Only \hl{17 of 120} label combinations are legal.
    \item Independent argmax emits invalid tuples on \hl{12.55\%} of Chinese
      rows.
    \item The official metric scores each field on its own, so an invalid tuple
      still keeps \hl{44.3\%} of the weighted field credit.
  \end{itemize}
}

\block{3\,$\cdot$\,Setup}{
  \begin{itemize}
    \item Chinese anchor: 2,000 paragraphs from 49 reports;
      \texttt{\small hfl/chinese-roberta-wwm-ext-large}.
    \item Five-way cross-fitting, three seeds, two protocols
      (document-disjoint primary).
    \item Paired report-cluster bootstrap, Holm-adjusted within each
      pre-specified family.
    \item External: English, French, Japanese (400 paragraphs each), Korean
      (500 PDF pages); 4 backbones $\times$ $\lambda\in\{0,0.3\}$ =
      \hl{32 arms}.
  \end{itemize}
}

\column{0.5}

\block{2\,$\cdot$\,Method: seven decision rules}{
  \begin{center}
    \includegraphics[width=\linewidth]{../figures/figure1_hierarchy.pdf}
    \srcnote{Figure 1 of the paper: the label hierarchy and the seven alternative
      decision rules}
  \end{center}
  \vspace{0.4em}
  \begin{itemize}
    \item One fine-tuned encoder with four independent heads; every rule reads
      the same cross-fitted probabilities.
    \item \hl{Projection} (greedy, top-down): pick PS; under PS\,=\,Yes pick the
      best substantive VT and ES; under ES\,=\,Yes the best substantive EQ.
      Always legal, no retraining.
    \item \hl{17-state decoding}: return the legal state with the highest summed
      log-score.
    \item Calibration: none, global, or conditional class biases.
      M0 is independent argmax.
  \end{itemize}
}

\block{Takeaway}{
  \begin{minipage}[c]{0.64\linewidth}
    Projection guarantees coherent ESG records without retraining, but it is
    not a route to a higher official score. For audit use, make validity a
    precondition and pick the metric that matches the unit at which errors
    have consequences.
  \end{minipage}\hfill

\block{6\,$\cdot$\,Why the metrics disagree}{
  \begin{itemize}
    \item Projection's N/A net is positive and its substantive net negative in
      all five corpora, yet tuple accuracy rises in every one.
    \item Joint decoding revises PS on \hl{339 of 12,000} rows: 225 become
      correct, 114 wrong, yet whole-row correctness there falls
      \hl{114 $\to$ 47}.
    \item Repairing a parent rarely rescues a row whose children stay wrong;
      breaking a correct parent always loses it.
  \end{itemize}
}

\block{7\,$\cdot$\,For audit use}{
  \begin{itemize}
    \item Validity is a \hl{precondition} for a usable record, not evidence that
      the record is right.
    \item A repair can hide an inconsistency, so a deployed validity layer
      should \hl{log the rows it repaired}.
    \item Choose the metric by how outputs are used:
      \begin{itemize}
        \item records $\to$ tuple accuracy among valid outputs
        \item single-field actions $\to$ that field's F1, or recall for a rare
          class
        \item portfolio statistics $\to$ class-level scores, keeping validity
        \item leaderboards $\to$ official wF1, but not for gaps under 0.008
      \end{itemize}
  \end{itemize}
}
