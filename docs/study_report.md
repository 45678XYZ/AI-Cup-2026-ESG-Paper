# 一、主張

## 1. 論文主張什麼

**一句話**：在具硬性階層的標籤空間中，逐欄 macro-F1 無法識別輸出是否自洽。

**示範方式**：我們拿兩個規則，它們**都**把輸出限制在 17 個合法狀態內，差別只在挑哪一個。

- **投影**（M1）：由上而下決定，父欄位定了就不回頭
- **17-state 解碼**（M4）：把 17 個合法組合整組評分，取最高

**結果**：官方指標偏好解碼器，整列正確率偏好投影。**兩個指標對同一批預測給出相反的排序。**

## 2. 為什麼這個主張站得住

**① 它不需要基線。** 對比的兩邊都是受約束的方法，所以「你們 baseline 太弱」「換強一點的模型就沒事」打不到。

**② 它不需要事後採用的指標。** 用的兩個量 —— 官方 weighted macro-F1 與整列正確率 —— **都在計畫裡事先寫好**。

**③ 它是構造性示範，不是非偵測。** 「我們沒測到差異」會被檢定力打掉；「我們造出兩個規則，兩個指標排序相反」不會。

## 3. 它不主張什麼

| ❌ 不主張 | 為什麼 |
|---|---|
| 階層約束提升效能 | 我們自己證明沒有 |
| 官方指標選錯了 | 逐欄 macro-F1 是多欄位任務的標準做法。我們講**性質**，不講**錯誤** |
| 合法性是免費的 | 未經結構化訓練的模型上有小幅代價 |
| 我們的方法比較準 | 我們提供一個保證，不比誰預測得準 |

## 5. 標準做法會違反它，而指標不在乎

模型用四個獨立 softmax 各自取 argmax，**架構上沒有任何東西阻止它自相矛盾**。

12,000 列中 **1527** 列非法（12.725%），而且 **95.2% 是同一種失效**：

| 違反的規則 | 次數 |
|---|---|
| `promise_status=No` 卻設了子欄位 | 699 |
| `evidence_status=No` 卻設了 `evidence_quality` | 755 |
| `promise_status=Yes` 卻沒設子欄位 | 47 |
| `evidence_status=Yes` 卻沒設 `evidence_quality` | 26 |

**指標公式沒有任何一項依賴四欄的聯合組態** → 合法性的權重**精確等於 0**（定義即可證）。

一個結構上不可用的答案，平均仍收下 **44.3%** 的加權逐欄分數。

### 四個欄位，沒有任何兩個同號

1. 強制合法在**逐欄指標上扣分**（四個 λ=0 全負，三個顯著）
2. 強制合法在**整列正確率上加分**（7/7，全部 p < 0.001）
3. 改用解碼器**兩個符號同時反轉**
4. 結構化訓練**把逐欄的代價抹平**（λ=0.3 三個全部 |Δ| < 0.001）

⚠️ **不可寫成劑量關係**：非法率 10.20 / 11.77 / 12.55 / 19.75% 對應代價 -0.005 / -0.007 / **-0.001** / -0.008，**不是單調的**；n=3 且非法率與基準分數共線 r = -0.81，兩種解釋不可識別。**只能寫符號模式。**

⚠️ **這七個對比是探索性的**，不構成 Holm 家族。

## 8. 為什麼會這樣 —— 逐類別的帳

投影在 `evidence_quality` 上只有一個動作：**把祖先不成立的預測改成 `N/A`**。

```
賺：N/A          +0.016 ~ +0.036   ← 1 個類別
賠：Clear        -0.007 ~ -0.033   ← 2 個類別
    Not Clear    -0.047 ~ -0.068
```

**macro 對四類等權平均，一賺打不過兩賠。**

全體的帳：修好 **822** 欄、弄壞 **637** 欄，但賺的幾乎全在 `N/A`（**+759**），賠的幾乎全在實質類別（**-574**）。

⚠️ **被拿掉的那些分數，是模型「先說沒有證據、又去評證據品質」拿到的。**
**所以逐欄指標上的下降不是模型變差，是指標收回它一開始就不該付的分數。**

**而解碼器為什麼相反**：它的目標函數是 `argmax Σ_t (log p_t + b_t)` —— **那就是「逐欄分數的和」**，本來就在最佳化逐欄指標。代價是它會用不可靠的欄位推翻可靠的欄位（`ps` 0.873 vs `vt` 0.492），整列因此崩掉。

> ⭐ **解碼器是「對齊指標」的約束解碼；投影是「對齊連貫性」的約束解碼。**

## 9. 為什麼階層本身幫不上

階層的**全部**資訊只有一句話：「父欄位否定時，子欄位為 `N/A`」。

| 判斷 | 模型表現 | 階層有意見嗎 |
|---|---|---|
| 這一欄該不該填 `N/A` | **77–88%（本來就準）** | ✅ 唯一決定的事 |
| 若不是，該填哪一個 | **0.493（很差）** | ❌ 完全沒意見 |

**階層約束的是模型本來就會的部分；模型不會的部分，它一個字都沒說。**

## 10. 排除替代解釋

| 質疑 | 回答 |
|---|---|
| 「因為你們只在事後施加」 | 訓練期 arm 動了參數。三個架構上非法率降 **59–67%**，官方指標 **p = 0.0604 / 0.4272 / 0.5145，全部不顯著** |
| 「因為你們那顆 backbone」 | **四個 checkpoint**，非法率 10.20%–19.75%，結論一致 |
| 「模型夠強就不會矛盾了」 | ⭐ **RoBERTa-base（11.77%）比 RoBERTa-large（12.55%）還低。非法率不是模型強弱的代理量** |
| 「你們換指標換到顯著」 | 主證據只用兩個**預先指定**的量 |

⚠️ 三個 architecture screen 皆為探索性；**最佳 p 值 0.0604**，必須連同「總共跑過三個」一起報告。

2. 49 個 cluster，檢定力有限；cluster 大小 4–91
3. **測的是 constraint 不是 representation** —— 未比較 17-class 聯合建模或 classifier chain。⚠️ 17 個狀態中 **7 個支撐數 ≤ 26、2 個為 0**，此規模下的失敗無法區分於資料稀疏
4. **投影在逐欄指標上有代價** —— 不可寫成「免費」
5. 兩個指標是事後採用的，已降為敘述
6. **試過的 screen 總數**：七個決策規則 + 訓練期 arm + 三個 backbone 檢查
7. seed 同時決定切分與訓練隨機性，變異來源無法拆解
8. 單一超參數設定，未做敏感度分析

## 16. 措辭紅線

| ❌ 不可寫 | ✅ 改成 |
|---|---|
| 合法性是免費的 | 在未經結構化訓練的模型上有小幅代價，該代價是指標收回付給矛盾答案的分數 |

## 18. ⚠️ 最強的攻擊與回答

### 攻擊

> 你們設計了方法、訓練完、分析完，發現官方指標上沒有提升。於是換了評估指標然後宣稱有顯著提升。這不就是繞一個彎製造顯著嗎？

### 必須承認的三件事

1. **C-wF1 與 hF 是事後採用的。** 已降為敘述、不進 Holm 家族。
2. **C-wF1 可逐項還原成官方指標** —— 是重新記帳，不是新量測。
3. **投影在未經結構化訓練的模型上，官方指標確實會扣分。** 我們自己報出來。

### 守得住的四件事

1. **主證據只用兩個預先指定的量**，攻擊失去著力點
2. **對我們不利的結果留著**：`M4-M1` 顯著更差
3. **抵銷是我們自己報出來的發現**，不是被抓出來的漏洞
4. **核心示範不需要基線**：兩個都合法的規則被排出相反順序

### 界線

**metric shopping** = 換到顯著就只報那一個。
**metric study** = 全部家族完整報告、包含不利的、並標明哪些是事後採用。

⚠️ **我們在後者，但這是靠「全部報告」守住的，不是靠運氣。**

# 四、方法（寫 Methods 用）

## 19. 模型與協定

- Backbone：`hfl/chinese-roberta-wwm-ext-large`（24 層、hidden 1024），revision 已釘
- 共享編碼器 + 四個獨立線性 head，`EPOCHS = 12`，last-3 checkpoint averaging
- 兩種 protocol：`pdf_group`（document-disjoint，計畫指定的主要）與 `row_strat`（same-document）
- 每個 protocol × 3 seeds × 5 rotations，每列在 Test 恰好出現一次

⚠️ **`±` 是三個 seed 的樣本標準差**，反映的是整條管線（切分 + 訓練）的變異，**不是模型穩定度，也不是信賴區間**。

## 20. 決策階段的三種規則

| | 做什麼 | 輸出合法嗎 |
|---|---|---|
| **M0** 獨立 argmax | 四欄各自取 argmax | ❌ 12.6% 非法 |
| **M1** 投影 | 由上而下，子欄位限制在父欄位允許的值 | ✅ 構造保證 |
| **M4** 17-state 解碼 | 對 17 個合法狀態算 `Σ_t (log p_t + b_t)` 取最高 | ✅ 構造保證 |

M2／M3／M5／M6 是在 M1／M4 之上加 class-bias calibration（global 或 conditional），bias 只在 Calibration partition 上擬合。

⚠️ **calibration 的目標是每個欄位自己的 macro-F1，在套用輸出規則之前評估** —— 這是刻意的，讓 M6-M3 能隔離出 decoder。代價是「幫到自己欄位的 bias 可能在下游被抵銷」，論文須載明。

## 21. 統計方法

- **Paired PDF-cluster bootstrap**，10,000 次重抽，`BOOTSTRAP_SEED = 20260814`
- **重抽單位是 PDF（49 個 cluster，大小 4–91），不是列**
- 兩個方法的差值在**同一次重抽**上計算
- 判定用 `p_Holm < 0.05`；區間是**未校正的** 95% 百分位區間

### 推論家族分層（A 於 8/24 拍板）

依 `docs/inference_families.md`，約 25 個檢定分成家族與探索層，**依「在看到結果之前寫在哪份文件裡」歸類**，不依效果大小：

| 層 | 內容 | 結果 |
|---|---|---|
| **家族 1（確認性）** | 官方 wF1 × 五個對比 | **5/5 不顯著** |
| **家族 2（預先指定 secondary）** | 整列正確率 × 同五個 | M1-M0 顯著好；M4-M1 顯著差 |
| **家族 3（預先指定）** | Regime gap，七法全報 | 七個全部通過 |
| **家族 4（預先登記）** | Structural arm H2 | 不顯著 |
| **探索性** | C-wF1、hF、三個 screen、跨 arm 的兩個對比 | 全部報告，不支撐任何主張 |
